# Shaffer Softworks

Open-source projects for smarthome, Home Assistant, and Android.

## About

Shaffer Softworks builds custom integrations and tools for home automation and connected devices—including Home Assistant custom components, Android device management, WebRTC intercom, and IoT firmware.

**Website:** [shaffersoftworks.tech](https://shaffersoftworks.tech)

## Highlighted projects

- **[hyperhdr-ha](https://github.com/Shaffer-Softworks/hyperhdr-ha)** — HyperHDR custom component for Home Assistant
- **[Android-Management](https://github.com/Shaffer-Softworks/Android-Management)** — Manage Android devices from Home Assistant using Google's Android Management API
- **[WebRTC-signaling-server](https://github.com/Shaffer-Softworks/WebRTC-signaling-server)** — Standalone WebRTC signaling server for LAN intercom, with a dashboard
- **[Android-WS-Player](https://github.com/Shaffer-Softworks/Android-WS-Player)** — Android WebSocket player for Home Assistant
- **[esp32-intercom](https://github.com/Shaffer-Softworks/esp32-intercom)** — ESP32 intercom client
